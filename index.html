Política de Privacidade — Matrix Omni LITE

Última atualização: 24 de novembro de 2026 • Versão 26.4.1

1. Visão Geral

A extensão Matrix Omni LITE auxilia operadores de atendimento e suporte técnico na organização e produtividade do fluxo de trabalho no Matrix CRM, oferecendo atalhos, personalização visual, registro operacional local, consulta de instabilidades e sugestões de resposta com Inteligência Artificial.

2. Dados Armazenados Localmente

As configurações, temas, prompts personalizados, base de conhecimento (FAQ), registros de Ordens de Serviço (O.S.), alarmes, métricas de produtividade e chaves de API configuradas pelo operador são armazenados exclusivamente no navegador do usuário via chrome.storage.local. Não operamos servidores próprios de rastreamento ou coleta comercial.

3. Uso de APIs de Inteligência Artificial

Somente quando o usuário aciona recursos de IA (sugestões de resposta, refinamento de texto ou transcrição de áudio), os dados necessários para gerar a resposta são enviados diretamente para o provedor escolhido pelo operador:

  • Google Gemini API (generativelanguage.googleapis.com)
  • Groq API (api.groq.com)
  • OpenRouter API (openrouter.ai)

4. Permissões do Navegador

  • storage e unlimitedStorage: persistência local de configurações e registros.
  • notifications e alarms: alertas e lembretes configurados pelo operador.
  • tabs e activeTab: sincronização e foco de abas do CRM quando solicitado.
  • scripting: carregamento sob demanda de módulos utilitários acionados pelo usuário.
  • system.cpu e system.memory: leitura local de saúde do sistema para o Eco-Mode.
  • browsingData: limpeza exclusiva de cache temporário (sem remover senhas ou sessões).
  • declarativeNetRequest: aplicação de regras locais estáticas para exibição de painel integrado e bloqueio de rastreadores listados.

5. Compartilhamento e Venda de Dados

Não vendemos, alugamos ou transferimos dados de usuários para corretores de dados, anunciantes ou terceiros fora das integrações de IA explicitamente acionadas pelo operador.

6. Exclusão de Dados e Contato

Todos os dados armazenados localmente podem ser apagados a qualquer momento limpando as configurações da extensão ou desinstalando-a do Google Chrome.

Suporte e Contato: Para solicitações sobre privacidade ou suporte técnico, utilize o e-mail de contato oficial informado na ficha desta extensão na Chrome Web Store.
